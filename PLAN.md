# План NetWatch

Обновлено 06.11.2026. Приоритет пользователя: сначала продукт, после него курсовая.

Главная инструкция: [IMPLEMENTATION_GUIDE.md](docs/IMPLEMENTATION_GUIDE.md). Она определяет архитектуру, контракты, порядок кода, стенд, ML, классификацию и критерии приёмки.

## Принятые направления

- Go: захват и разбор пакетов, потоки, оконные признаки, доставка, API, incidents.
- Python: обучение и inference; сначала Isolation Forest, затем GRU-прогноз на PyTorch.
- Host- и destination-service-признаки: для распределённых событий нужна агрегация всех наблюдаемых источников.
- PostgreSQL, локальная устойчивая очередь сенсора, HTTP/JSON batch; web UI на TypeScript/React.
- Docker-стенд с реальным container traffic и независимой разметкой; Linux — первый профиль эксплуатации.
- После минимума: supervised классификатор известных классов, калибровка вероятностей, unknown/abstention.
- Production-ready — только после пройденной приёмки заданного профиля, не название текущего прототипа.
