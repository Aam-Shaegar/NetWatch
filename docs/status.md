# Состояние NetWatch на 6 ноября 2026

Шаг 0 завершён. Локальный монорепозиторий содержит Go, ML на Python, React/TypeScript, общие контракты, архитектурные решения, CI и изолированный стенд. Исходная версия 0.1 сохранена в истории Git. Рабочие веса модели и Go-декодер предстоит реализовать.

## Что проверено

- В основной папке прошли `make bootstrap`, `make doctor test build compose-check` и `scripts/check_fixtures.py`. Пройдены Go-тесты с race detector, 12 ML-проверок и 6 тестов старого прототипа. Один deprecation warning в тестовом клиенте Starlette. CI настроен, удалённый workflow ещё не запускался.
- Go и Python валидируют один пример окна. Есть контрольные PCAP/PCAPNG, включая повтор SYN, IPv6, VLAN и неполный пакет. Следующий критерий приёмки — проверить результат нового Go-декодера по этим записям.
- Окружение PyTorch прошло проверку GRU forward на CPU. База PostgreSQL поднималась и отвечала на `SELECT 1`. Интерфейс собран и просмотрен в браузере.
- Короткий запуск Docker дал 50 успешных запросов и запись 589 TCP-пакетов. Повторная проверка в основной папке с плавной нагрузкой дала 91 успешный запрос из 91. PCAP, журнал запросов и манифест хранятся под `data/runs/`. Контейнеры сценариев остановлены.
- Внешний образец IoT-23 Somfy-01 скачан под `data/raw/iot23/`, прочитаны 8 276 записей, интервал 5 087,822 с. Размер и SHA256 находятся в `data/manifests/iot23-somfy-01.json`. Проверка разметки и подготовка обучающей выборки впереди. Восстановление — `python3 scripts/fetch_sample.py`.

## Следующий шаг

Написать `internal/capture` и `internal/decode` для offline PCAP, затем получить проверенные окна Go из тестовых записей, стенда и внешнего образца. Для обучения собирать независимые stable/ramp/flash-crowd запуски. CIC-IDS2017 и CIC-DDoS2019 оставить для отдельной проверки и последующей классификации. Рабочие параметры и команды — в `docs/runbooks/data.md` и `docs/runbooks/development.md`.

## Offline replay на Go

Реализовано потоковое чтение PCAP/PCAPNG в ограниченном профиле и команда `netwatch-sensor replay`. Результат — JSONL с метаданными пакетов, отдельными статусами исключения и счётчиками. На Somfy-01 прочитаны 8276 записей: 7059 IP и 1217 non-IP. На записи лаборатории прочитаны 589: 491 decoded и 98 truncated. С независимым парсером Scapy сверены число и время всех записей, адреса, длины и транспортные порты успешно декодированных пакетов.

Эталон двух SYN дал два TCP-пакета по 40 IP-байт. Шаг 3 — реализовать flow tracker и окна host/service, проверить объединение этих двух пакетов в одну попытку. Состояние ML и стенда описано выше. Рабочий процесс: проверки → просмотр diff → коммит → пуш → сверка удалённой ветки и CI. Локальная ветка archive/pre-publication хранит прежнюю историю с данными курсовой и исключена из публикации.
