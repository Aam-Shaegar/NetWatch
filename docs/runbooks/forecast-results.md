# Сравнение детекторов на лабораторной паузе

Использованы разбиения коллекции шага 7, модель IF шага 8 и правило открытия
инцидентов шага 9. Сеть обучалась на 1 214 последовательностях. Для выбора
контрольной точки использованы 187 нормальных последовательностей validation.
Лучшей оказалась эпоха 33 из 38. Порог GRU на нормальном calibration равен
3,975544. Часовой бюджет калибровки равен одному ложному окну.

| Раздел | Метод | Пропущено пауз | Ложные окна / час | Ложные инциденты / час | Задержка открытия, с |
|---|---|---:|---:|---:|---:|
| Validation | Фиксированный порог | 0 из 1 | 29,39 | 5,88 | 13,12 |
| Validation | EWMA | 0 из 1 | 14,69 | 2,94 | 13,12 |
| Validation | Isolation Forest | 0 из 1 | 67,59 | 5,88 | 13,12 |
| Validation | GRU | 1 из 1 | 41,14 | 8,82 | — |

| Test | EWMA | 0 из 1 | 2,99 | 0 | 13,02 |
| Test | Isolation Forest | 0 из 1 | 0 | 0 | 13,02 |
| Test | GRU | 1 из 1 | 5,99 | 1,50 | — |

Рабочей лабораторной моделью остаётся Isolation Forest. Среди моделей с
реализованным serving она обнаружила валидационную паузу и дала меньше ложных
инцидентов, чем GRU. Бюджет ложных окон на validation превысили все четыре
метода. EWMA показала наименьшую частоту ложных инцидентов на validation.
Пропущенной паузе задержка не присваивается.

На validation наблюдалось 0,3403 часа размеченного нормального трафика, на test —
0,6681 часа. GRU выставила оценки в 404 из 500 пригодных тестовых окон, включая
398 из 481 размеченного нормального окна. Остальные пригодные окна пришлись на
прогрев. По одной паузе в каждом разделе нельзя оценить надёжность обнаружения
других сетевых аномалий. Тестовый раздел ранее использовался для отчёта шага 8.
