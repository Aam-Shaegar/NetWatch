# Причины пропусков и изменения passive-v2

Исправления проверены повторно на записях прежнего внешнего эксперимента. После изучения результатов эти записи стали материалом разработки. Отдельная запись Philips Hue добавлена после выбора правил для контроля ложных тревог.

## Изменения

Эталон собирается по пяти полным обычным минутам того же датчика. Граница равна медиане плюс максимум из медианы и шести медианных абсолютных отклонений. Сохранены абсолютные минимумы интенсивности. Пустая измеренная минута отличается от отсутствующего наблюдения. Старые запросы с отношением к норме продолжают оцениваться прежними условиями.

Пятисекундные пики вычисляются внутри минуты. Для UDP и ICMP проверяется доминирование протокола именно в соответствующем отрезке. Протокольный пик сравнивается также с границей общей нагрузки. Сигнал выдаётся в конце минуты.

Для журналов входов добавлена история предыдущих четырёх минут. Считаются события одной учётной записи, по которой появился новый отказ в текущей минуте. Десять отказов и доля 90% сохранены. Исправлен выбор аккаунта, когда пользователь с большим числом отказов, но низкой их долей заслонял пользователя с выполненными обоими условиями.

Импорт пакетов вычисляет SYN-попытки и завершённые рукопожатия из метаданных Go. Повторный SYN с тем же номером последовательности считается одной попыткой. Пары SYN/SYN-ACK и итоговое ACK связываются по адресам, портам и номерам TCP.

Для SQLi, XSS, эксплуатации, утечки, подмены адресов, DNS-туннеля, медленных заголовков, распределённой перегрузки и пятисекундных моделей TCP нет подходящих положительных эпизодов. Показатели для них остаются неизмеренными.

## Повторная проверка

| Тип | Было | Стало | Задержки, секунды |
|---|---:|---:|---|
| Сканирование | 1/3 | 3/3 | 58,335; 77,548; 183,683 |
| Общие всплески | 0/9 | 7/9 | 5,963–58,399 |
| UDP | 0/4 | 4/4 | 5,963–58,399 |
| ICMP | 0/1 | 1/1 | 26,498 |
| Перебор | 2/6 | 3/6 | ESXi 585,101; Azure 56,173; O365 5,000 |

Строгий счёт требует начала нового инцидента и не увеличивается при смене фазы уже активной тревоги. Несколько строк могут относиться к одному эпизоду.

В первичном нормальном контроле 245 минут после исключения пяти калибровочных минут на запись. Ноль ложных инцидентов для сканирования, общих всплесков, UDP и ICMP. Исторические 265 минут использовали одну калибровочную минуту на запись. В дополнительном контроле Philips Hue оценены 1 308 минут на адресе 192.168.1.132, также ноль ложных инцидентов для четырёх правил. Для SYN на этой записи нет подходящих измерений. Ложные тревоги классификатора паролей этим экспериментом не измерены.
