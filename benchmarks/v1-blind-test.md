# Независимое сравнение NetWatch v1

Две связки из [первого раунда](v1-model-comparison.md) проверили на новых захватах с прежними весами и порогами. До расчёта прогнозов зафиксировали порядок выбора по эпизодам трёх известных атак. Первый критерий — полнота обнаружения в среднем по типам, второй — полнота правильного определения типа, третий — частота ложных инцидентов на час в среднем по контрольным источникам. Эпизод засчитывали, если хотя бы одно размеченное окно дало соответствующий результат.

Тест включал 20 эпизодов TCP-сканирования из одной лаборатории, по одному эпизоду UDP- и ICMP-флуда и три эпизода вне каталога. Контроль обычного трафика составил 12,37 хост-часа и 8 903 окна. [Сканирования ITA](https://zenodo.org/records/3558350) · [Интервалы атак UCM](https://doi.org/10.17632/83j5bh76hj.1) · [UNSW](https://iotanalytics.unsw.edu.au/attack-data.html) · [CERTH](https://zenodo.org/records/15082260) · [Aalto](https://research.aalto.fi/en/datasets/iot-devices-captures/) · [Almorabea](https://zenodo.org/records/7772015)

Штатный анализатор вернул `insufficient_data` для всех 11 846 окон с неизвестным счётчиком потерь. Ниже приведён диагностический прогон, допускающий такое значение. Все решения обоих стеков по каждому окну совпали с офлайн-расчётом. Числа инцидентов сверены с PostgreSQL и операторским API.

| Показатель | Random Forest → RF | Gradient Boosting → RF |
|---|---:|---:|
| Обнаружены известные эпизоды | 22/22 | 22/22 |
| Правильно указан тип эпизода TCP / UDP / ICMP | 9/20 · 1/1 · 1/1 | 6/20 · 1/1 · 1/1 |
| Обнаружены аномальные окна, включая атаки вне каталога | 1 593/1 597 | 1 109/1 597 |
| Верный тип или верный `Unknown` среди обнаруженных окон | 59/1 593 | 34/1 109 |
| Ложные тревожные окна | 8 124/8 903 | 5 962/8 903 |
| Ложные инциденты / на хост-час по всему контролю | 892 / 72,14 | 88 / 7,12 |

По заранее выбранным критериям лидирует Random Forest на обоих этапах. Его преимущество в трёх TCP-эпизодах относится к одному захвату. На штатном трафике CERTH обе связки пометили 5 878 из 5 895 окон как аномальные. Объединение последовательных тревог дало всего четыре инцидента для каждой связки. Готовность v1 к эксплуатации остаётся неподтверждённой.
