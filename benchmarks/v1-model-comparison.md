# Первое сравнение моделей NetWatch v1

Испытание реализации `d57a834`, профиль `traffic-v3`, окна по 5 секунд. На августовских записях обучили пять детекторов и четыре классификатора с seed 42. По сентябрьским записям выбрали пороги и Random Forest для обоих этапов. Для октябрьских атак использовали внешние контрольные записи Orion и IoT-23 Somfy. Разбиение сохраняло захваты целиком. В октябре был один эпизод каждого известного типа и один эпизод вне каталога. [Farm-Flow](https://zenodo.org/records/10964648)

Штатный режим вернул `insufficient_data` для всех 1 809 окон основного прогона. В диагностической копии разрешили неизвестный счётчик потерь пакетов. Обе связки проверили с ранее выбранными порогами. Из 1 800 размеченных окон 547 были аномальными, 1 253 — нормальными. Верным ответом для атаки вне каталога считался `Unknown`.

| Детектор → классификатор после правил | Обнаружено аномальных окон | Правильный ответ среди обнаруженных | Ложные инциденты за 1,74 хост-часа |
|---|---:|---:|---:|
| Random Forest → Random Forest | 488/547 | 334/488 | 14 |
| Gradient Boosting → Random Forest | 497/547 | 342/497 | 9 |

На отдельном контроле Gotham за 2,12 хост-часа обычной работы одного устройства связки дали 149 и 0 ложных инцидентов соответственно. Сравнение на этих тестах определило двух участников следующего слепого раунда. [Gotham](https://zenodo.org/records/14502760) · [Независимый тест](v1-blind-test.md)
